# 沉浸式非遗音景疗愈虚拟现实体验软件 V1.0.0

- 著作权人：陕西理工大学
- 版本：V1.0.0
- 技术栈：Node.js 标准库 + 浏览器 Canvas / Web Audio
- 运行方式：本地单机，默认端口 4105

## 目录结构

```
server.js          HTTP 服务、路由、鉴权与限流
lib/               服务端模块（存储、认证、会话、指标、报告等）
public/            控制台与体验端页面（HTML / CSS / JS）
package.json       运行配置
```

## 启动

```bash
node server.js
```

启动后访问 `http://127.0.0.1:4105`。首次启动会在 `data/` 下生成业务样本与令牌密钥；可通过环境变量 `PORT` 与 `DATA_DIR` 指定端口与数据目录。

## 能力边界

本软件以浏览器全屏场景与双声道声像实现沉浸式体验，不包含 Unity 引擎、OpenXR、VR 头显驱动、6DoF 头部追踪、手柄震动、HRTF 双耳渲染与视频流投屏；不提供医疗诊断，不承诺治疗效果。
